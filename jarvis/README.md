# Jarvis — локальная панель Windows

## Запуск

1. Установите Node.js LTS с https://nodejs.org/ (версия 22 или новее).
2. Сохраните `index.html`, `server.cjs` и `Start-Jarvis.cmd` в одну папку.
3. Запустите `Start-Jarvis.cmd` двойным щелчком.
4. Откройте http://127.0.0.1:4317 в Google Chrome или Microsoft Edge.
5. На вкладке Jarvis нажмите «Включить микрофон» и разрешите доступ.

Окно сервера должно оставаться открытым. Установка npm-пакетов не нужна. HTA больше не подходит для голосовой части. Интерфейс, стили и вся логика помощника находятся в одном `index.html`; сервер нужен для запуска локальных программ и запросов к источникам информации. Доступ к серверу открыт только на этом компьютере.

## Команды

- «Джарвис, открой Блендер» — название должно совпадать с названием в быстром пуске. Путь к программе задаётся вручную. Для надёжного распознавания английской программы можно назвать кнопку по-русски.
- «Джарвис, добавь дело завтра в 15:00 купить продукты». Поддержаны сегодня, завтра, послезавтра или дата ГГГГ-ММ-ДД; время ЧЧ:ММ. Если дата не названа, дело добавляется без даты. Произвольные даты словами пока не поддерживаются.
- «Джарвис, открой сайт example.com». Адрес требуется произнести или ввести как домен. Произвольные названия сайтов пока не преобразуются в адреса.
- «Джарвис, какая погода» — город задаётся на вкладке Jarvis. Данные Open-Meteo.
- «Джарвис, курс доллара / евро / юаня» — курс ЦБ, не котировки обменника. Можно ввести трёхбуквенный код валюты.
- «Джарвис, что такое фотосинтез» — справочный поиск в Википедии со ссылкой на источник. Это не универсальная нейросеть и не поиск новостей по всему интернету.
- «Джарвис, выключи микрофон» — выключение голосом. Кнопка выключения доступна независимо от команды.

Можно сказать имя отдельно и в течение 10 секунд произнести команду. Печатный ввод не требует имени. Во время ответа микрофон распознавания приостанавливается, чтобы помощник не отвечал самому себе. После перезапуска страницы микрофон всегда выключен.

Голос выбирается из русских голосов, установленных в системе и доступных браузеру. Определённый актёрский голос не включён. Распознавание может передавать аудио сервису браузера и требовать интернет. Если браузер сообщает сетевую ошибку распознавания, команды можно вводить текстом. Индикатор относится к прослушиванию этой панелью: глобальную громкость микрофона Windows и другие приложения он не контролирует.

## Свои команды

На вкладке «Команды» укажите название, фразы через `;` и тело JavaScript-функции. Затем включите «Разрешить выполнение моих команд». Совпадение фразы точное, без учёта регистра и части пунктуации. Пользовательские команды проверяются раньше встроенных.

Пример для фразы `рабочий режим`:

```js
await api.say('Открываю рабочий календарь.');
await api.open('https://calendar.google.com');
api.addTask({
  title: 'Проверить рабочий план',
  date: '2026-10-20',
  time: '09:00',
  details: 'Проверить задачи на день'
});
```

Открытие локального файла:

```js
await api.open(String.raw`C:\Windows\System32\notepad.exe`);
```

Также доступны `await api.weather('Москва')`, `await api.currency('EUR')`, `await api.search('История компьютеров')`. Код исполняется в странице и имеет доступ к её данным; редактор предназначен для вручную добавленного доверенного кода, а не для автоматической установки ответов из интернета.

## Хранение и ограничения

Программы, заметки, дела, команды и настройки сохраняются в localStorage выбранного браузера для адреса http://127.0.0.1:4317. Очистка данных браузера удаляет их. Данные старого HTA или файла, открытого двойным щелчком, автоматически сюда не переносятся.

Дела — список с датами и статусом выполнения; уведомлений по расписанию и фонового будильника в этой версии нет. Сервер не принимает подключения из локальной сети, не выполняет команды командной строки из распознанного текста и открывает только путь или HTTP(S)-ссылку. Голосовой ввод сам по себе не является проверкой личности: любой голос рядом с включённым микрофоном может дать команду.

Для полностью отдельного современного окна потребуется оболочка WebView2 или другая desktop-сборка. В этой версии панель работает в современном браузере с локальным сервером, поскольку HTA не поддерживает нужное распознавание речи.
