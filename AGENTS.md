# Организация проектов

- Для каждого самостоятельного задания используй отдельную папку проекта. Продолжая существующее задание, переиспользуй его папку; Jarvis находится в `jarvis/`.
- По указанию владельца после выполнения задания и соответствующих проверок делай коммит и push изменений проекта в этот репозиторий. Не включай посторонние изменения.
- Не добавляй ключи, пароли, пользовательские данные, зависимости и временные файлы. Сообщай, в какую ветку отправлены изменения, и давай ссылку на папку проекта.
